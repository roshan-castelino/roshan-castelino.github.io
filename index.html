Featured project

Icarus

Custom FPV quadcopter

Icarus is a small FPV quadcopter built around an ESP32-S3-WROOM-1 board and brushed coreless motors. We designed the drone from scratch so it can be flown from a phone over Wi-Fi or Bluetooth.

All the circuits and software are custom-made, so everything is optimised for this project.
